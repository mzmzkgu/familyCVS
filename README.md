# 우리가족 편의점 (familyCVS)

집에 있는 생필품/식료품을 바코드로 스캔해서 등록·관리하는 가족용 재고 관리 앱.

## 구성
- `index.html` — 등록 / 기록 / 공유메모 3개 탭으로 구성된 단일 페이지 앱

## 주요 기능
- 브라우저 내장 `BarcodeDetector` API로 사진에서 바코드 인식 (여러 이미지 전처리 변형을 시도해 인식률 보완, 자릿수별 다수결 투표로 오인식 보정)
- 바코드 직접 입력도 지원
- 날짜별로 등록 기록 그룹핑, 완료 체크 기능
- 가족 공유메모 (등록자: 아빠/엄마/강욱/진욱)
- 백엔드: Google Apps Script 웹앱 (Google Sheets를 DB로 사용), 30초 로컬 캐시
- 다크모드, 글씨 크기 조절 지원
